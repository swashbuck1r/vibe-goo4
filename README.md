# goo4

A Go REST API application deployed on CloudBees HiveVibe platform.

## 🚀 Quick Start

### Run Locally

```bash
make run
```

Visit: http://localhost:8080

### Build and Test

```bash
make build
make test
```

### Deploy to Production

```bash
# Build Docker image and push to ECR
make docker-push

# Deploy to Kubernetes
make k8s-deploy

# Or do both in one command
make deploy
```

Your app will be available at: **https://goo4.arch.beescloud.com**

## 🔄 CI/CD

This repository includes a CloudBees workflow that automatically:

1. Builds Docker image on every push to `main`
2. Pushes image to ECR
3. Deploys to Kubernetes via Helm
